# Category Rules: Marketing/SEO

1. Metadata & OpenGraph: Provide unique, descriptive `<title>`, `<meta name="description">`, canonical URLs, and OpenGraph tags (`og:title`, `og:image`, `og:description`).
2. Performance & Core Web Vitals: Prioritize fast First Contentful Paint (FCP) and low Cumulative Layout Shift (CLS).
3. Search Crawlers: Maintain valid `robots.txt` and `sitemap.xml` entries. Avoid broken internal links.
