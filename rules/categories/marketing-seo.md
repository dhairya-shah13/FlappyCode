# Marketing & Search Engine Optimization (SEO) Rules

- [SEO-001] Provide a unique, descriptive `<title>` tag (50–60 characters) and `<meta name="description">` (120–160 characters) on every public page.
- [SEO-002] Define explicit canonical URLs (`<link rel="canonical" href="...">`) on all indexed pages to prevent duplicate content penalties.
- [SEO-003] Implement Open Graph (`og:title`, `og:description`, `og:image`, `og:url`) and Twitter Card meta tags for rich social sharing previews.
- [SEO-004] Embed valid Schema.org structured data (JSON-LD) for SoftwareApplication, Organization, Article, and FAQ page types.
- [SEO-005] Structure content semantically with exactly one `<h1>` per page reflecting the primary topic, followed by properly nested `<h2>` and `<h3>` headings.
- [SEO-006] Provide meaningful, descriptive `alt` attributes for every image asset to optimize image search and screen reader accessibility.
- [SEO-007] Maintain an automatically generated, up-to-date `sitemap.xml` and standard `robots.txt` disallowing internal admin and search endpoints.
- [SEO-008] Use clean, keyword-relevant, lowercase URL slugs separated by hyphens; avoid unreadable numeric IDs or nested query parameters.
- [SEO-009] Optimize Core Web Vitals to protect organic search rankings: ensure Time to First Byte (TTFB) < 800ms and Largest Contentful Paint (LCP) < 2.5s.
- [SEO-010] Ensure absolute mobile-friendliness with responsive viewports, readable font sizes, and avoidance of full-screen intrusive interstitials.
- [SEO-011] Eliminate redirect chains and fix broken internal links immediately; return proper 404/410 status codes for deleted content.
- [SEO-012] Build a logical internal linking hierarchy connecting cornerstone product features with high-intent landing pages.
- [SEO-013] Provide multilingual `hreflang` annotations if content is localized across international locales.
- [SEO-014] Ensure social preview images (`og:image`) conform to recommended 1200x630 pixel dimensions with under 5MB file sizes.
- [SEO-015] Serve all pages over HTTPS with valid SSL certificates to fulfill search engine security ranking requirements.
